7. 반응형 §9.7

  • PC/태블릿 (기본): 모드토글 텍스트 표시, 빠른속도 칩 노출, 집중확대 1.55배
  • 폰 (≤640px): 토글 아이콘만, 빠른속도 숨김(.speed-quick{display:none}), 집중확대 1.15배, 제목 16px, 곡선택 드롭다운 숨김
  • .sheet-wrap = width:100%; max-width:1000px; margin:0 auto — 악보는 어느 화면이든 중앙·최우선

8. 구현 완료 체크 (§10.4)

  • 악보(abcjs SVG)가 화면 대부분을 차지
  • 재생 시 현재 음표 amber 하이라이트
  • 전체/집중 토글 동작
  • 집중모드에서 현재 줄 확대 + 다음 줄 흐림
  • 집중모드 재생 중 줄 바뀌면 자동 스크롤
  • 로 휘슬 1옥타브↓ 재생 (악보 표기는 불변)
  • 바우런/스푼 ON 시 리듬 반주가 멜로디와 박자 동기
